# تحويل اللعبة إلى APK بدون حاسوب

هذا المشروع يغلّف ملفات اللعبة (مجلد `www`) داخل تطبيق أندرويد باستخدام Capacitor، ثم يبنيه GitHub على خوادمه مجانًا. اللعبة تعمل داخل التطبيق بلا إنترنت.

> حالة المشروع: بُني هذا المشروع فعليًا على GitHub Actions أكثر من مرة وفُحص الـAPK الناتج (التوقيع بالمفتاح الثابت، الاتجاه العمودي، إذن الاهتزاز). الإصدار الحالي من اللعبة هو **الإصدار 2** (شرحه الكامل في `README-GAME.md`). إن فشل أي بناء، انسخ نص الخطأ من صفحة Actions.

## الخطوات من الهاتف

1. أنشئ حسابًا مجانيًا على github.com، ثم أنشئ مستودعًا جديدًا باسم `player-career` (يُفضَّل **Private** لأن مفتاح التوقيع داخله).
2. من صفحة المستودع: **Add file ← Upload files**، ثم ارفع الملف **`project.zip`** كما هو (لا تفكّه)، ثم **Commit changes**.
3. **Add file ← Create new file**. في خانة الاسم اكتب بالضبط:
   `.github/workflows/build-apk.yml`
   ثم الصق داخله محتوى الملف **`build-apk.yml`** المرفق، ثم **Commit changes**.
4. افتح تبويب **Actions**. سترى «Build Android APK» يعمل، ويستغرق 5 إلى 10 دقائق. إن لم يبدأ: اختره ثم **Run workflow**.
5. عند ظهور علامة ✓ خضراء، ادخل **Releases** (في الصفحة الرئيسية للمستودع) وحمّل **`player-career.apk`**.
6. افتح الملف على هاتفك. سيطلب أندرويد السماح بالتثبيت من هذا المصدر فوافق. قد يظهر تحذير Play Protect وهو طبيعي لتطبيق لا يأتي من متجر Play.

## إن وصلك المشروع كملف واحد `player-career-apk.py`

1. على حاسوب فيه Python 3: شغّل `python3 player-career-apk.py` فيظهر مجلد `player-career-apk` بكل الملفات (بما فيها المجلد المخفي `.github`).
2. أنشئ مستودعًا Private على GitHub، ثم ارفع **محتوى المجلد كله** إليه على الفرع `main` (بـ git، أو بسحب الملفات والمجلدات إلى صفحة Upload files على الحاسوب). ملف `project.zip` غير لازم هنا.
3. اتبع الخطوتين 4 و5 أعلاه: انتظر تبويب Actions ثم حمّل APK من Releases.

## تحديث اللعبة لاحقًا

عدّل الملفات داخل `www` (أو ارفع `project.zip` جديدًا) وسيُبنى APK جديد برقم أعلى تلقائيًا. المفتاح ثابت (`debug.keystore`)، فيُثبَّت التحديث فوق النسخة القديمة **دون فقدان الحفظ**. لا تغيّر `appId` في `capacitor.config.json`، وإلا يُعدّه أندرويد تطبيقًا مختلفًا.

## الحفظ

مسيرتك المحفوظة في المتصفح لا تنتقل تلقائيًا إلى التطبيق (تخزين منفصل). انقلها هكذا: في المتصفح **الإعدادات ← تصدير الحفظ**، وفي التطبيق **شاشة البداية ← استيراد**.

## محتويات المشروع

| الملف | وظيفته |
|---|---|
| `www/` | اللعبة نفسها (نسخة مطابقة لمشروع اللعبة) |
| `README-GAME.md` | شرح اللعبة وملفاتها وأنظمتها واختباراتها |
| `capacitor.config.json` | اسم التطبيق ومعرّفه `com.hossam.playercareer` ولون الخلفية |
| `package.json` | يحدد إصدار Capacitor (6.x) وإضافة `@capacitor/app` لزر الرجوع |
| `scripts/prepare_android.py` | يضبط الأيقونة وشاشة البداية وألوان الأشرطة والاتجاه العمودي وإذن الاهتزاز ورقم الإصدار |
| `debug.keystore` | مفتاح التوقيع الثابت. احتفظ بنسخة منه، ولا تنشره |
| `.github/workflows/build-apk.yml` | وصفة البناء على GitHub |
